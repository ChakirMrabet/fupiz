Frequently Asked Questions

Find answers to the most common questions about Fuipiz.

Is Fuipiz free to use?

Yes! Creating an account and shortening links is completely free. You get access to premium features like custom aliases, password protection, and click analytics at no cost.

Can I edit a short link after creating it?

Currently, you cannot edit the destination URL of a short link once it has been created to prevent abuse. However, you can easily disable or delete the link from your dashboard and create a new one.

How does the password protection work?

When you set a password on a link, anyone who clicks the short URL will be redirected to an unlock screen. They must enter the correct password before being forwarded to your original destination.

What happens when a link expires?

If you set an expiration date, the link will automatically stop working after that precise date and time. Visitors will see a message indicating the link is no longer active.
